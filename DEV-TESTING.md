# Dev Testing

This file talks about how to load the extension as a developer.

## Chrome 

1. *Open Chrome's extensions manager.* Enter chrome://extensions in Chrome's address bar.
2. *Enable Developer mode.* Turn on the Developer mode switch in the upper-right corner.
3. *Click Load unpacked.* Select your local color-contrast-chrome folder — the one containing manifest.json. Don't select the manifest file itself.

## Firefox

1. *Open Firefox's debugger page.* Enter about:debugging#/runtime/this-firefox in Chrome's address bar.
2. *Click Load Temporary Add-on.* Select manifest.json in your local color-contrast-chrome folder.
